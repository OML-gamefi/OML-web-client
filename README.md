## 开发指南

### 环境要求

- Node.js v20.10.0
- pnpm

### 本地开发

1. 克隆项目到本地：

   ```bash
   git clone https://github.com/OML-gamefi/OML-web-client.git
   ```

2. 安装依赖：

   ```bash
   cd OML-web-client-react
   pnpm install
   ```

3. 启动开发环境：

   ```bash
   pnpm run dev
   ```

4. 访问 <http://localhost:3000> 查看项目
